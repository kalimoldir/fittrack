# FitTrack — фитнес-система

Сайт на Python (Flask): пользователь выбирает тип тренировки и уровень подготовки, а система составляет план тренировки.

## Использованные паттерны

### 1. Factory (Фабрика)
**Где в коде:** класс `WorkoutFactory` в файле `workouts.py`.

**Что делает:** по слову из формы ("cardio", "strength", "yoga") создаёт нужный объект: `CardioWorkout`, `StrengthWorkout` или `YogaWorkout`.

**Почему выбран:**
- создание объектов находится в одном месте;
- чтобы добавить новый вид тренировки, достаточно создать класс и добавить одну строку в фабрику, остальной код менять не нужно;
- сайт (`app.py`) не зависит от конкретных классов тренировок.

### 2. Strategy (Стратегия)
**Где в коде:** классы `BeginnerStrategy` и `AdvancedStrategy` в файле `strategies.py`.

**Что делает:** определяет, как выполняется тренировка на выбранном уровне: время, число подходов, отдых и интенсивность.

**Почему выбран:**
- уровень подготовки легко менять, не переписывая сами тренировки;
- без Strategy пришлось бы делать отдельные классы для каждого сочетания (например, "кардио для начинающих") или использовать много `if/else`;
- новый уровень добавляется одним новым классом.

## Как паттерны работают вместе
Factory отвечает за то, **что** создать (тип тренировки), а Strategy за то, **как** она выполняется (уровень подготовки).

## Запуск
1. Установить Flask: `pip install flask`
2. Запустить: `python app.py`
3. Открыть в браузере: http://127.0.0.1:5000
